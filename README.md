# Tarea HW-05: Migraciones en Django

## Diagrama de base de datos
![Diagrama](./docs/diagrama.png)

## Descripción
Este proyecto demuestra el uso de migraciones en Django.  
Incluye modelos relacionados entre sí: `Categoria`, `Proveedor`, `Producto`, y `Orden`.

Cada modelo se añadió en pasos separados, con su respectiva migración.  
El objetivo es comprender cómo Django aplica los cambios de los modelos a la base de datos mediante migraciones.
